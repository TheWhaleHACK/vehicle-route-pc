Маршрут Торжок → Бологое: реальные геоданные и прогноз уклона

Для получения РЕАЛЬНОГО маршрута на компьютере:
1. Установите Python 3, если его нет. Используются только стандартные библиотеки.
2. Подключитесь к интернету и дважды щёлкните Загрузить_реальный_маршрут.bat.
   Либо запустите: python generate_real_data.py
3. После сообщения «Готово» откройте index.html двойным щелчком.

Скрипт один раз получает автомобильную геометрию дороги Торжок → Бологое через
OSRM (OpenStreetMap) и высоту SRTM90m через Open Topo Data. Он записывает
route.csv, vehicle.csv, model_report.json и обновляет data.js. Далее приложение
работает без интернета. Исходные CSV до запуска скрипта остаются учебными.

Модель: гребневая регрессия (ridge), признаки — уклоны за предыдущие 250, 500,
1000 м и текущая высота; прогноз — средний уклон следующих 500 м. Отчёт
содержит среднюю абсолютную ошибку на последней, отложенной части маршрута и
сравнение с простым прогнозом по предыдущим 500 м. После проверки модель
переобучается на всём маршруте для показа в приложении. Она обучена на одной
дороге и не является надёжной навигационной или водительской системой.

Масса, базовая скорость и моделируемая телеметрия не поступают с реальной
CAN-шины. Геодезическая высота SRTM90m не равна точному профилю дорожного
полотна. Фактический режим движения, знаки, ограничения и условия дороги
не учитываются. Рекомендация скорости — исключительно учебная симуляция.
